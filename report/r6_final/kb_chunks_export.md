```
1. Run Page (生產執行操作頁面)
1.1 前端控制面板
[Start] 啟動: 按下啟動鈕 [Start] 時，即可依據使用者所設定的條件啟動CHROMA 3200。

[Stop / Beep Off] 停止與關閉警告音: 運轉期間，如按下停止鈕 [Stop] 時，CHROMA 3200會立即停止所有運轉動作。

[One Cycle] 單循環: 當使用者按下單循環鈕 [One Cycle] 時，CHROMA 3200即停止由入料盤區輸入產品到 Trolley，並將測試後的產品分類到 Output。

[Reset] 清除錯誤: 當系統偵測到機台有異常狀況或是錯誤狀況時，操作畫面會將所發生的錯誤訊息顯示於螢幕告知使用者，當使用者將所出現的錯誤排除後，使用者可以按下清除錯誤鈕 [Reset]，系統會重新偵測一次，如果仍有相同或發現其他的錯誤時，畫面仍會出現相關所發生的錯誤訊息告知使用者，反之畫面會恢復到使用者操作或設定畫面。

[Retry] 重試: 當系統偵測出錯誤，當使用者將所發生錯誤位置的產品放置好時，使用者可以按下重試鈕 [Retry]，機台會重新執行目前狀態。

[Skip] 忽略: 當系統偵測出錯誤，當使用者將所發生錯誤位置的產品取出時，使用者可以按下忽略鈕 [Skip]，機台會忽略此一產品。

[Tray Change] 入料盤區換料盤: 當入料盤區的供貨料盤已無產品，需將此一料盤更換時，使用者可以按下入料盤區換料盤鈕

[Tray Change]，機台會自動將此一料盤更換並放置於空料盤區。

[Stack Unload] 所有料盤退出: 當使用者按下料盤退出降鈕 [Stack Unload] 時，機台會自動將所有料盤下降至底部。

(※機台於生產中不得任意放置料盤於入料盤區與空料盤區，如入料盤區需放置未測料盤與空料盤區需放置空料盤時，使用者需至<User>控制畫面中執行Stack Unload後，方可於入料盤區放置未測料盤進去)

[Initial] 復歸: 當機台開機後或是發生馬達相關錯誤時，操作者可以按下復歸鈕 [Initial]，機台會重新尋找原點回到工作生產狀態。

(※當機台未執行Initial動作時，Start鈕將不會亮起，此時代表機台未處於待命狀態)

(※當馬達執行過Servo Off動作時，機台必須執行Initial動作)
```
