## 四、综合结论

### 四项改动叠加效果

```
R1: 基线(LLM零-shot改写 + 纯Dense + 阈值0.0)
         Precision=0.36  BM25=0

R2: +阈值0.01 + 术语表注入
         Precision=0.69  BM25=4(2题)  ← 噪声减40%

R3: +中文bigram BM25(无简繁转换)
         BM25=5(3题)  ← bigram对匹配字符有效

R4: +opencc简繁转换
         BM25=9(6题)  ← 简繁统一后更多命中
```

### 做得好的
- **Precision 翻倍**：有效精度从 0.36 提升到 0.69
- **Recall 无损**：所有相关切片均被检索到，无遗漏
- **BM25 从零激活**：0→9 次命中，覆盖 60% 测试题
- **噪声减少 38%**：平均每题传递给 LLM 的切片从 5 条降到 3.1 条

### 仍可继续优化的
1. **BM25 仍未全覆盖**：Q1(Offset Setting)、Q2(Auto Alignment)、Q5(Timer Setting)、Q9(Event Log) 的 BM25 仍为 0。这些题的特点是查询词在文档中不连续出现或使用不同表述
2. **Cobra 等小切片**：178 字的切片内容有限，考虑合并相邻小切片
3. **术语表自动更新**：新文档入库后触发术语提取
4. **P0: LLM 相关性过滤**：当前 Precision 天花板 0.69，要突破需 LLM 二次判断
